# Сайт игры Miner 1899

Страница игры и сама игра. Код игры — в репозитории [miner-1899](https://github.com/Z0rD4n0v1ch/miner-1899).
Публикуется на GitHub Pages:
**https://z0rd4n0v1ch.github.io/1899/**

## Что где лежит

```
1899.github.io/
├── index.html                 # страница игры
├── play/index.html            # сама игра (копия miner-1899.html)
├── img/                       # скриншоты для страницы (WebP)
│   ├── overview.webp
│   ├── biomes.webp
│   ├── creatures.webp
│   └── mobile.webp
├── assets/
│   ├── logo.webp              # логотип 600 px, 129 КБ — его показывают браузеры
│   ├── logo.png               # запасной логотип для старых браузеров
│   ├── favicon.png            # значок вкладки
│   ├── apple-touch-icon.png   # значок на экране iPhone
│   └── og.jpg                 # картинка-превью для Telegram, ВКонтакте и т.п.
├── .github/workflows/deploy.yml
└── README.md
```

Вся страница с картинками весит около 280 КБ. Исходный логотип 4096 px (20 МБ) на сайт не кладётся.

## Как опубликовать

1. Положи эти файлы в репозиторий и отправь на GitHub.
2. Один раз: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. После каждого `push` в `main` сайт пересобирается сам (вкладка **Actions**, 1–2 минуты).

## Как обновить игру

После выпуска новой версии в основном репозитории скопируй файл игры сюда:

```bash
cp ../miner-1899/miner-1899.html play/index.html
git add play/index.html
git commit -m "Игра 1.6.2"
git push
```

Брать файл нужно **после** `./sync.sh release`: тогда в игре правильный номер версии.
Сохранения игроков хранятся в их браузере и при обновлении не теряются.

После выпуска стоит обновить и раздел «Что нового» в `index.html`.

## Если переименуешь репозиторий

Адрес сайта поменяется. В `index.html` поправь две строки с полным адресом:
`og:image` и `og:url` (нужны для превью ссылки в мессенджерах). Остальные ссылки на странице относительные и поменяются сами.

## Проверить у себя

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Открывать `index.html` двойным щелчком тоже можно, но кнопка «Играть» в таком режиме ведёт в папку, а не в игру — через локальный сервер всё работает как на сайте.
